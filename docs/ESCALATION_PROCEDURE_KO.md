# 학생 제출 절차 — 미확인 상태의 문의 순서

제출일: 2026-10-31 (Asia/Seoul). [사용자 원문 기록](../data/student-escalation-procedure-2026-10-31.json).

[단계별 관찰 후 설계 과제](STAGE_TIMING_02_KO.md)는 ‘지정석이 비었고 외출 정보도 없을 때, 어떤 확인을 거쳐 학생의 상태를 판단할지’였습니다. 사용자는 다음 순서를 제출했습니다.

| 단계 | 학생이 제시한 문의 대상 | 방법 |
| --- | --- | --- |
| 1 | 동급생이나 친한 아이 | 물어봄 |
| 2 | 리더나 12학년 | 물어봄 |
| 3 | 사감쌤 | 물어봄 |
| 4 | 교장쌤 | 전화함 |

이는 학생이 설명한 절차 순서입니다. 학교의 공식 규정으로 확인되었거나 네 단계를 실제로 모두 거친 사례가 보고된 것은 아닙니다. ‘리더’의 구체적 역할도 아직 정하지 않습니다. 문의 대상의 순서는 학생 제출 기여이고 아래 상태·조건 정리는 Codex 보조 설계입니다. 새로운 관찰 회차나 시간 측정 자료가 아닙니다.

## 소프트웨어로 옮길 부분과 아직 정하지 않은 부분

초기 상태는 **미확인**, 문의 대상은 위 순서로 기록할 수 있습니다. 후속 답변에서 사용자는 친구에게 **‘정확히 어디로 갔는지’** 듣고 **‘더 확인은 안해’**라고 설명했습니다. [종료 기준 원문](../data/student-peer-stopping-rule-2026-10-31.json)에 두 답변을 함께 보존했습니다.

따라서 첫 문의에서 구체적인 행선지를 들으면 **추가 확인 없이 문의를 종료한다**는 기준은 학생 제출 규칙입니다. 문의 종료 상태는 **‘행선지 전달받음 — 친구 제보에 근거한 종료’**로 표현합니다. 이는 공식 확인·허가 확인·실제 위치 검증 완료를 뜻하지 않습니다. 구체적인 행선지를 듣는 조건을 생략하고 ‘누가 답하면 종료’로 일반화하지 않습니다.

| 상황 | 보조 설계 초안 | 학생 기준·검토 상태 |
| --- | --- | --- |
| 첫 문의에서 친구가 구체적인 행선지를 알려줌 | 추가 문의를 종료하고 친구 제보임을 표시 | 학생 종료 기준 제출됨; 독립 대조는 하지 않는다고 설명 |
| 첫 문의에서 행선지를 구체적으로 듣지 못함 | 미확인으로 두고 다음 대상에 문의 | 다음 단계 진행은 기존 순서를 바탕으로 한 보조 해석 |
| 두 번째 이후 문의에서 답변을 얻음 | 근거와 출처를 별도로 기록 | 각 단계의 종료 기준은 아직 구체적으로 제출되지 않음 |
| 현재 단계에서 해결하지 못함 | 다음 문의 대상으로 진행 | 원문의 순서를 바탕으로 한 조건 해석; 명시적 조건은 미제출 |
| 답변끼리 충돌하거나 상대에게 연락되지 않음 | 해결되었다고 자동 처리하지 않음 | 재시도·기다림·다음 단계 진행 기준 미정 |
| 마지막 문의 후에도 해결하지 못함 | 미해결 상태를 유지하고 별도 검토 필요 표시 | 최종 담당·완료 조건 미정 |

친구의 구체적 행선지 전달 후 종료는 학생이 설명한 현행 기준이며 나머지 조건들은 보조 설계 초안입니다. 현재 구현된 기능으로 간주하지 않습니다. 친구가 잘못 알고 있을 가능성, 허가 여부와 실제 위치는 이번 규칙으로 검증되지 않습니다. 학교 공식 기준으로 채택되었다는 근거도 없습니다. 자동 결석 판정이나 자동 연락 기능으로 확대하지 않습니다.

## 시간 모델에 주는 의미

최초 질문 이후에도 해결되지 않으면 문의 단계가 늘어날 수 있습니다. 따라서 질문 횟수뿐 아니라 **어느 단계까지 갔는지**, **그 단계에서 해결되었는지**가 모델의 입력 후보입니다. 조건부 종료 초안에서는 매번 네 단계 시간을 모두 더하는 고정 절차로 취급하지 않습니다. 단계별 소요시간, 상대를 찾거나 기다리는 시간과 해결 비율은 미확인입니다. 기존 11초·14초·13초·17초·23초를 특정 문의 대상에 배정하거나 가상 계수를 현장 값으로 만들지 않습니다.

기존 시간 의존관계 모델은 정해진 작업 경로의 종료시간을 계산합니다. 답변의 신뢰성이나 조건에 따른 문의 경로 선택을 검증하는 기능은 별도 설계가 필요합니다. 이 문서만으로 그 기능의 완성을 주장하지 않습니다.

## 다음 단계: 종료 기준을 가상 사례로 검토

아래는 보조자가 구성한 가상 테스트 초안입니다. 실제 관찰 자료나 학생이 이미 작성·검토한 테스트가 아닙니다.

| 가상 입력 | 예상 동작·검토 상태 |
| --- | --- |
| 친구가 구체적인 장소를 알려줌 | 제출 규칙상 문의 종료. 친구 제보라는 출처와 독립 검증 안 함을 유지 |
| 친구가 ‘어딘가 나간 것 같다’고만 답함 | 구체적 행선지 기준을 충족하지 않음. 미확인 유지·다음 단계는 보조 초안 |
| 친구가 구체적인 장소를 말했으나 실제로는 틀림 | 현재 규칙은 여전히 문의를 종료할 수 있음. 절차 종료와 사실 정확성이 다를 수 있다는 반례 |

다음 학생 과제는 세 번째 사례에서 어떤 오판이 생길 수 있는지 본인의 말로 한 가지 적고, 그 위험을 받아들일지 규칙을 바꿀지 이유와 함께 판단하는 것입니다. 현재 운영을 바꾸라는 지시나 추가 측정 요청은 아닙니다. 이 검토를 실제 제출 후에 테스트의 승인 기준으로 연결합니다.
