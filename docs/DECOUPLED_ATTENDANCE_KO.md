# 출석 확인과 야자 시작의 의존관계 변경

보고일: 2026-10-27. 출처: 사용자 설명과 후속 답변. **사생회에서 공동으로 논의·결정했고 다음부터 시행할 계획**입니다. 아직 새 방식이 시행되거나 효과가 측정된 상태로 기록하지 않습니다. 준모가 혼자 제안·결정했다고 주장하지 않습니다.

## 결정된 절차

- 학생은 착석 후 바로 야자를 시작합니다.
- 사생회가 출석 여부를 별도로 확인합니다.
- 반장이 한 반씩 확인·보고하는 기존 절차를 새 절차의 기준선과 구분합니다.
- 새 출석 확인의 시작 시점·소요시간·담당 인원·확인 방법은 아직 구체적으로 검증하지 않았습니다.

핵심은 **야자 시작이 출석 확인 완료를 기다리지 않도록 작업 간 의존관계를 바꾸는 것**입니다. 출석 확인 자체의 작업량이 없어졌거나 더 빨라졌다는 결론은 아닙니다.

## 조건부 모델과 측정 결과의 구분

기존 103초 착석·160초 반별 구간은 이전 절차에 대한 동료 측정 보고입니다. 기존에 공부 시작이 모든 출첵 완료를 기다렸고, 구간 사이 공백이 없었으며, 새 절차의 착석시간도 103초로 같다는 **가정 아래**:

```
기존 공부 시작 = 103 + 160 = 263초
변경안 공부 시작 = 103초
모델상 차이 = 160초
```

이는 조건부 의존관계 계산입니다. 새 방식에서 **실제로 2분 40초를 절약했다**, **사생회 업무가 줄었다**, **학습시간이 그만큼 늘었다**고 주장할 수 없습니다. 기존 자료에는 실제 야자 시작의 원시 시각도 없으므로 기존 공부 시작 263초조차 별도 관측값이 아닌 가정입니다.

이 알려진 시작 경로는 확인 업무를 맡지 않는 학생을 대상으로 합니다. 사생회 담당자도 학생이며 확인 중에는 같은 시작·절감 효과를 적용할 수 없습니다. 모델에서 담당자 공부 시작은 확인 업무 뒤의 별도 미확인 경로로 둡니다. 160초에 명단 120명을 곱해 전체 학습시간이 회복되었다고 계산하지 않습니다.

새 확인 작업의 시간이 미확인이어도 공부 시작 경로와 분리되었다면 두 값은 별도로 취급할 수 있습니다. 미확인 확인시간은 0초가 아니라 **미확인**입니다. 이를 보존하는 의존관계 모델을 별도로 구현하고 기존 합성 대기행렬 모델과 구분합니다.

## 다음 시행에서 검증할 것

같은 시계에서 착석 완료, 실제 공부 시작, 사생회 확인 시작·완료를 기록합니다. 친구 등 관찰자가 무엇을 기록했는지도 역할별로 남깁니다. 실제 시작 시점과 학습의 질·집중도를 동일시하지 않습니다.

운영 가설: 새 방식에서는 공부가 출석 확인 완료 전에 시작할 수 있다. 실제로 계속 확인 완료를 기다리거나 확인 중 공부가 반복해서 중단된다면 그 한계를 기록합니다. 확인이 먼저 끝나는 경우도 순서 그대로 기록하며 의존관계 제거가 항상 큰 시간 차이를 보장한다고 가정하지 않습니다.

계획과 실행, 사용자 본인의 공동 논의 참여와 단독 발안, AI가 작성한 모델·코드는 각각 구분합니다. 최초 측정 자료를 새 절차의 결과로 재분류하지 않습니다.
