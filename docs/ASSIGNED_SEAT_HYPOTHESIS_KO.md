# 지정석·빈자리 예외 확인 가설과 담당 교대

보고일: 2026-10-27. 사용자 설명으로 확인된 사항은 다음과 같습니다.

- 사용자 본인도 사생회 소속이며 본인 또는 다른 부원이 돌아가며 확인할 예정입니다.
- 학생별 **지정석**입니다.
- 대부분 자리가 차 있으니 빈자리 위주로 확인하면 빨라질 것이라는 생각은 사용자가 제시한 **검증 전 가설**입니다.
- 사생회의 별도 확인·착석 후 야자 시작은 공동으로 결정한 다음 시행 계획입니다. 이 공동 결정과 사용자 개인이 제시한 빈자리 확인 아이디어를 구분합니다.

교대 주기, 한 번에 실제 활동하는 인원, 빈자리 수와 새 확인시간은 아직 제공되지 않았습니다. 매일 한 명이라고 임의로 확정하지 않습니다.

## 절차 가설

1. 지정석이 있는 확인 대상 구역을 훑습니다.
2. 빈자리 또는 불확실한 자리를 예외로 추가 확인합니다.
3. 확인 결과를 정리합니다.

지정석은 예외를 찾을 단서가 됩니다. 그러나 빈자리를 찾는 스캔·이동 시간은 필요하며, 빈자리가 곧 확인된 결석이라는 규칙은 세우지 않습니다. 기존 방식과 같은 완료 기준으로 확인 정확성을 비교해야 합니다. 실제 이름·좌석 배치·개인별 출결을 앱이나 공개 저장소에 입력하지 않고, 이 프로젝트에서는 익명 집계와 작업시간만 분석합니다.

## 시간 가설의 검증

서로 겹치지 않는 작업 구간으로 구분할 수 있을 때:

```
새 확인시간 = 구역을 훑는 시간 + 빈자리·불확실한 자리 추가 확인 + 결과 정리
```

동시에 하거나 섞여 진행되는 작업은 중복 합산하지 않습니다. 우선 새 확인 시작·완료의 전체 경과시간을 재고, 구분 가능한 세부 항목만 추가합니다. 빈자리 수가 0이어도 스캔·기록 시간이 자동으로 0이 되지 않습니다. “빈자리 수 × 일정 시간”만으로 전체 시간을 산출하지 않습니다.

초기 비교 질문: 새 방식의 전체 확인시간이 이전 **160초의 단일 참고 기록**보다 짧아지는가? 같은 확인 기준을 유지하는가? 실패한 경우에도 빈자리 수·담당자·예외 처리와 함께 기록합니다. 한 번 짧아졌다는 결과만으로 전체 조건에 일반화하거나 인과 효과를 확정하지 않습니다. 정확성도 재지 않았다면 유지되었다고 주장하지 않습니다.

## 역할별 공부 시작

- **다른 부원이 담당하는 차례:** 확인을 기다리지 않고 착석 뒤 공부를 시작하는 경로를 분석합니다.
- **본인이 담당하는 차례:** 본인의 확인 업무와 공부 시작을 따로 기록합니다. 새 업무시간을 모르면 본인의 시작 시각과 절감 시간도 미확인으로 둡니다.

교대는 업무를 나누는 계획입니다. 교대 그 자체로 전체 작업량이 줄어드는 것은 아닙니다. 담당자별 실제 활동시간과 확인 중 공부가 중단된 시간을 별도 기록합니다. 새 업무를 맡는 학생 모두가 동일한 160초를 절약한다고 계산하지 않습니다.

앱의 역할 선택은 계획을 이해하기 위한 모델 보기이며 실제 날짜별 담당 배정표가 아닙니다. 학생 본인이 제시한 아이디어·역할과 AI가 형식화·구현한 모델을 기여 기록에서 구분합니다.
