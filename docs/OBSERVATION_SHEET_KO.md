# 순차 인원 확인 관찰 기록지 — 빈 양식

이 파일은 다음 관찰을 위한 **빈 양식**입니다. 첫 보고 자료로는 친구가 재준 착석 103초와 8개 반 구간 합 160초를 받았습니다([기준선](PEER_TIMING_BASELINE_KO.md)). 그 자료의 원시 시각·관찰일·기기는 미확인이며, 아래 칸을 그 값으로 채워 새 측정을 한 것처럼 만들지 않습니다. 관찰이 허용되는지 먼저 확인하고 사람 이름·학번·개인 출결·벌점 기록은 넣지 마세요. 실제 기록은 공개 저장소에 자동 업로드하지 않습니다.

## 기록 방법

하나의 연속 타이머를 사용하고 관찰 시작을 0초로 둡니다. 아래 사건과 반별 표를 모두 같은 타이머의 경과 초로 기록합니다. 시뮬레이터에 옮길 때는 첫 확인 시작 A를 빼서 엔진의 t=0에 맞춥니다.

- D<=A<=F일 때 준비·진행 대기 `P=A-D`: ______초
- 확인·보고 `V=F-A`: ______초
- 마감 이후 전체 `T=F-D`: ______초

주관적인 진정 정도를 측정된 센서 값으로 취급하지 않습니다. P에는 착석·진정 외 진행 대기가 섞일 수 있습니다. 마감 전 카운트다운 길이를 P+V에 다시 더하지 않습니다. [구간 정의](SESSION_PHASES_KO.md)를 참고하세요.

- 확인 시작: 해당 반의 인원 파악을 시작한 순간.
- 확인 종료: 인원 파악이 끝나 보고할 준비가 된 순간.
- 보고 시작: 그 반의 결과를 사생회장에게 전달하기 시작한 순간.
- 보고 종료: 그 반의 전달이 끝난 순간. 다시 확인해야 한다면 익명 사건 코드로 별도 표시.

**호명이나 다른 절차를 새로 시키지 말고 현재 방식을 관찰합니다.** 반장이 미리 확인해 두었거나 확인 시작·종료가 눈에 보이지 않으면 해당 칸은 미측정으로 남기세요. 그 경우 우선 각 반의 차례 시작부터 보고 완료까지의 합친 구간만 기록할 수 있습니다. 합친 시간을 임의로 확인·보고 두 부분으로 나누지 않습니다. 아래 잔차 계산은 각 단계 시간이 실제로 구분된 세션에서만 가능합니다.

## 모델을 검증하는 계산

각 반 g에 대해:

```
c_g = 확인 종료 - 확인 시작
r_g = 보고 종료 - 보고 시작
보고 전 공백 = 보고 시작 - 확인 종료
다음 반 전환 공백 = 다음 반 확인 시작 - 현재 반 보고 종료
```

관찰한 작업 완료시간 `T_obs = 마지막 보고 종료 - 첫 확인 시작`.

현재 모델의 예측 `T_model = sum(c_g + r_g)`는 보고 전·반 사이 공백을 0으로 가정합니다. **잔차 `R = T_obs - T_model`**를 기록하세요. 순차 진행이 맞다면 R은 관찰된 공백들의 합과 일치해야 합니다. R이 음수라면 작업 겹침, 시간 정의 또는 측정 오류를 점검해야 합니다.

- `T_obs`: ______초
- `T_model`: ______초
- 잔차 R: ______초
- 누락된 작업·공백의 가능한 설명: ______

이 세션에서 얻은 시간을 다시 같은 세션에 적용한 결과는 독립 예측 검증이 아닙니다. 별도 세션을 남겨 두고 모델과 입력 선택 규칙을 고정한 뒤 검증해야 합니다. 허용 오차나 성공 기준은 결과를 본 뒤 유리하게 바꾸지 말고 사전에 문서화하세요.
