## 기록 방법

하나의 연속 타이머를 사용합니다. **첫 반의 인원 확인이 시작되는 순간을 t=0**으로 정하고, 예정 시각부터 그 순간까지의 지연은 별도로 기록합니다. 마지막 보고가 끝나는 시각까지의 상대 초를 적습니다. 예정 시각 기준 전체 지연과 실제 확인 작업시간을 섞어 비교하지 않습니다.

- 확인 시작: 해당 반의 인원 파악을 시작한 순간.
- 확인 종료: 인원 파악이 끝나 보고할 준비가 된 순간.
- 보고 시작: 그 반의 결과를 사생회장에게 전달하기 시작한 순간.
- 보고 종료: 그 반의 전달이 끝난 순간. 다시 확인해야 한다면 익명 사건 코드로 별도 표시.

| 익명 그룹 | 확인 시작 t | 확인 종료 t | 보고 시작 t | 보고 종료 t | 중단·재확인·기록 불확실성 |
| --- | --- | --- | --- | --- | --- |
| G01 | | | | | |
| G02 | | | | | |
| 추가 행 | | | | | |

행 수는 실제 확인 단위에 맞춰 늘립니다. 두 행은 예시용 빈 칸이며 실제 반 수나 인원에 대한 주장이 아닙니다. 동시에 정확히 보기 어려운 구간은 추측해 채우지 말고 미측정으로 남깁니다.

## 모델을 검증하는 계산

각 반 g에 대해:

```
c_g = 확인 종료 - 확인 시작
r_g = 보고 종료 - 보고 시작
보고 전 공백 = 보고 시작 - 확인 종료
다음 반 전환 공백 = 다음 반 확인 시작 - 현재 반 보고 종료
```

관찰한 작업 완료시간 `T_obs = 마지막 보고 종료 - 첫 확인 시작`.

현재 모델의 예측 `T_model = sum(c_g + r_g)`는 보고 전·반 사이 공백을 0으로 가정합니다. **잔차 `R = T_obs - T_model`**를 기록하세요. 순차 진행이 맞다면 R은 관찰된 공백들의 합과 일치해야 합니다. R이 음수라면 작업 겹침, 시간 정의 또는 측정 오류를 점검해야 합니다.
