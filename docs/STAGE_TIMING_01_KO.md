## 조건부 구간 합계

각 숫자가 해당 단계의 소요시간이고 순서대로 겹침·누락 없이 이어졌다는 조건에서 계산합니다. 별도로 측정한 전체 경과시간이나 원시 시작·종료 시각은 제공되지 않았습니다.

- 준비: 카운트다운 10 + 착석·진정 31 = **41초**. 착석·진정 자체는 31초이며, 이를 카운트다운 포함 41초와 구별합니다.
- 확인: 훑기 58 + 질문 17 + 질문 23 + 다시 체크 25 = **123초**.
- 전체 단계 합: 41 + 123 = **164초 (2분 44초)**.
- 질문 합: **40초**, 확인 합 123초의 **약 32.52%**.
- 질문 외 확인 단계 합: 훑기 58 + 다시 체크 25 = **83초**. ‘다시 체크’를 정리·기록으로 바꾸어 명명하지 않습니다.

이제 보고된 절차를 준비 → 훑기 → 질문1 → 질문2 → 재확인으로 표현할 수 있습니다. 이는 사용자가 제공한 절차 분해입니다. 고정 학생당 처리율, 일반적인 질문시간 계수, 재확인의 불필요성 또는 실제 절감 효과는 도출하지 않습니다.

## 앞선 기록과의 관계

앞서 [별도 질문 회차](INQUIRY_TIMING_01_KO.md)는 전체 확인 **103초**, 질문 **14초·13초**로 보고되었습니다. 이번 확인 단계 합은 **123초**, 질문은 **17초·23초**입니다. 후속 답변에서 사용자는 이번 자료가 **‘새로 측정한 다른 회차’**임을 명시했습니다. [회차 확인 기록](../data/stage-timing-session-confirmation-2026-10-30.json)이 최초 기록의 연결 미확인 상태를 해소합니다. 이전 수치를 수정한 것이 아닙니다.

현재 위원회 확인 관찰은 네 회차입니다. 착석·확인 전체 시간을 직접 보고한 기존 두 회차, 확인 103초와 질문 구간이 연결된 한 회차, 이번 단계별 한 회차를 구분합니다. 확인용 후속 답변은 별도 회차로 세지 않습니다. 초기 반별 확인의 친구 측정 기준선은 이 네 회차와 별도입니다.

이번 확인시간 123초는 단계별 조건부 합계이므로 README의 기존 직접 보고 합계 비교 시리즈 두 건에 합쳐 넣지 않습니다. 이전의 ‘답변 대기 중 다른 작업 없음’, 착석 직후 야자 시작 여부, 인원·외출 맥락도 옮기지 않습니다.

‘다시 체크 25초’에 무엇을 했는지 설명합니다. 빈자리만 다시 보았는지, 질문 답변을 자리·명단과 대조했는지, 전체를 다시 확인했는지 등 **실제로 한 행동**을 적습니다. 이 단계에서 새로 확인되거나 바뀐 판단이 있었는지도 기록합니다. 이미 끝난 회차의 세부 시간을 추측해 채우거나, 검증 전에 재확인 단계를 제거하지 않습니다.
