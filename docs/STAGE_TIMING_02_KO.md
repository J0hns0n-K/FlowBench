앞선 보고: [첫 단계별 관찰](STAGE_TIMING_01_KO.md). 확인 합은 45초 짧아졌지만 준비 합은 19초 길어져 전체 합은 26초 짧습니다. 확인 구간의 산술 차이 45초는 훑기 차이 12초, 질문 합 차이 29초, 재확인 차이 4초로 분해됩니다. 질문 변화가 전체 차이를 일으켰다는 인과 해석은 하지 않습니다. 질문 외 확인 단계도 83초에서 67초로 달라졌으므로 고정 훑기·재확인 시간을 가정할 수 없습니다.

질문 비중은 이번 확인 합의 11/78, 약 **14.10%**입니다. 질문을 없애면 그만큼 안전하게 시간을 줄일 수 있다는 뜻은 아닙니다. 이번 78초는 [기존 두 번째 직접 보고](SECOND_COMMITTEE_OBSERVATION_KO.md)의 78초와 우연히 같은 값이며 별도 회차·다른 산출 방식입니다. 당시 카페·수업 인원, 공부 시작 여부나 정확도 결과를 이전하지 않습니다.

위원회 확인 관찰은 현재 다섯 회차입니다. 직접 보고 착석·확인 전체 시간 두 회차, 별도 확인·질문 한 회차, 단계별 두 회차이며 친구가 잰 초기 반별 기준선은 별도입니다. 파생 합계는 기존 직접 보고 합계 시리즈에 합치지 않습니다.

## 다음 단계: 관찰을 판단 규칙으로 연결

추가 회차 측정 요청은 보류하고, 실제 도구가 어떤 판단을 지원할지 설계합니다. 다음 학생 과제는 가상 사례 **‘지정석은 비었지만 그 학생이 다른 자리에 있을 수 있다’**에서 다음을 본인의 말로 작성하는 것입니다.

1. 최초 훑기만 끝난 시점에 무엇을 알 수 있는가?
2. 그 학생의 상태를 결정하려면 어떤 정보가 더 필요한가?
3. 정보를 얻지 못했을 때 도구는 어떤 상태를 남겨야 하는가?

이는 소프트웨어의 입력·상태 전환·완료 조건을 정하기 위한 설계 과제입니다. 이후 사용자가 [문의 대상 순서](ESCALATION_PROCEDURE_KO.md)를 제출했습니다. 아직 증거 수용·종료 기준이나 구현 기능의 완성은 아닙니다. 현장 관찰과 제출 순서는 사용자 기여이고 합계 비교·해석·과제 구성은 Codex 보조 작업입니다.
